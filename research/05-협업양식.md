# 복사해서 쓸 협업 양식

아래는 팀 저장소의 이슈·PR·문서에 복사할 초안이다. 아직 GitHub 설정이나 자동화 파일로 설치하지 않았다. 빈칸은 해당 기능의 담당자가 채운다.

## 1. 업무 카드

```markdown
### 해결할 문제
사용자:
현재 불편:
이번 변경 후 결과:

### 범위
포함:
후속 작업으로 남길 것:

### 완료 조건
- [ ] 입력 ___ 에서 결과 ___ 를 얻는다.
- [ ] 실패 상황 ___ 에서 상태 ___ 를 반환한다.
- [ ] 실제 연결/계약 확인 방법과 결과를 남겼다.
- [ ] 필요한 문서·예시·버전을 갱신했다.

### 담당·일정
담당자:
검토자:
예상 크기: 0.5 / 1 / 2일
의존 이슈:
데모할 결과물:
```

## 2. PR

```markdown
### 문제와 변경
관련 이슈:
어떤 입력에서 무엇이 달라지는가:

### 확인 결과
정상 사례:
실패 사례:
실행한 검사·명령:
결과·로그·화면 링크:
아직 확인하지 못한 점:

### 영향
API/스키마/DB:
모델·프롬프트·데이터 버전:
배포·복구 시 필요한 작업:

### 검토 요청
특히 확인할 부분:
```

## 3. 에이전트 계약

```markdown
이름:
업무 책임:

출력 스키마·예시:
사용 도구·권한:
모델·프롬프트 버전:
근거 형식:
상태: success / needs_input / needs_review / error
타임아웃:
일시 오류 재시도 한도:
의미 수정 루프 한도:
외부 쓰기 유무·승인·중복 처리:
로그 항목:
정상 예시:
근거 부족 예시:
도구/모델 실패 예시:
담당자·검토자:
```
