## 이번 조사 범위

- 조직에서 이름에 FINAL이 포함된 저장소 144개를 목록화했다. 별도 AI/WEB 저장소가 포함될 수 있으므로 144개를 독립 프로젝트 수로 해석하면 안 된다.
- 후보 선정용 README 탐색 이후 **실질 비교 대상을 25개로 제한**했다. 비교표의 번호는 순위가 아니다.
- 18기 2팀은 README와 코드·설정·평가·서빙 관련 파일 17개를 확보해 핵심 경로를 점검했다.
- 추가 5개 팀은 학습·평가·워크플로 관련 총 10개 파일을 확인했다.
- 저장소 코드를 실행하거나 모델을 학습·배포하지 않았다. README의 성능 수치는 해당 팀이 보고한 값이며 이번에 재현한 결과가 아니다.
- “미확인”은 공개된 확인 범위에서 근거를 찾지 못했다는 뜻이다. 구현이 없다고 단정하지 않는다.
- 진행 중인 저장소도 있으므로 모든 사례가 수료 당시 최종 제출본이라고 가정하지 않는다.

출처 원문과 파일 SHA는 [조사 출처 기록](./sources.json)에 남겼다. 파일 SHA는 파일 내용의 식별자이며 실행 결과나 저장소 전체의 특정 커밋을 뜻하지 않는다.
