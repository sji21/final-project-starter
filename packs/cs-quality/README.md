# CS 답변 검수

이 팩은 합성 예제와 고정 응답을 포함합니다. 모델 품질 평가 자료가 아닙니다.

- manifest.json: 화면 이름·업무·라벨·학습 태스크
- prompts/: 추출·검토·검증 역할의 지시문
- example.json: 실제 API와 같은 입력 구조
- demo-responses.json: 예제와 정확히 일치할 때만 사용하는 고정 응답

이 폴더를 복사하고 manifest ID와 폴더 이름을 맞추면 공통 코드 수정 없이 새 팩으로 등록됩니다.
실제 도메인 데이터와 사람이 검수한 평가셋은 별도로 준비해야 합니다.
